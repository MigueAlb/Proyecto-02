# 🏮 Mercado Nocturno del Barrio Chino de Guayaquil

Sitio web informativo dedicado a promocionar el **Mercado Nocturno del Barrio Chino de Guayaquil**, destacando sus actividades culturales, gastronomía, emprendimientos y experiencias comunitarias.

El proyecto busca reunir información relevante sobre el evento en un espacio digital accesible, facilitando su difusión y promoviendo la participación de visitantes, emprendedores y organizaciones interesadas en colaborar.

## Vista general

El Mercado Nocturno se desarrolla en el centro de Guayaquil, en el sector de la **calle Sucre, entre Chile y Pedro Carbo**. Es un espacio que reúne a comerciantes, artistas, emprendedores y visitantes mediante actividades culturales, gastronómicas y comerciales.

Este sitio web permite conocer el evento, explorar sus principales atractivos y acceder a diferentes espacios de participación.

![Vista previa del proyecto](resources/images/Pagina%20de%20inicio.png)

## Características principales

- **Información del evento:** presentación del Mercado Nocturno, sus actividades y ubicación.
- **Historia y cultura:** contenido sobre el Barrio Chino de Guayaquil y su importancia cultural.
- **Experiencias:** información sobre gastronomía, entretenimiento y emprendimientos.
- **Agenda de actividades:** espacio para consultar próximos eventos, fechas y horarios.
- **Emprendedores:** información y formulario de interés para participar en futuras ediciones.
- **Aliados:** presentación de organizaciones colaboradoras y propuestas de colaboración.
- **Comunidad:** espacio dedicado a experiencias, opiniones y sugerencias de los visitantes.
- **Diseño adaptable:** interfaz orientada a su visualización en computadoras, tabletas y dispositivos móviles.

## Instalación y ejecución

El proyecto está desarrollado como un sitio web estático, por lo que no requiere instalar dependencias mediante npm ni configurar una base de datos.

### 1. Clonar el repositorio

```bash
git clone https://github.com/MigueAlb/Proyecto-02.git
```

### 2. Acceder al proyecto

```bash
cd Proyecto-02
```

### 3. Ejecutar el sitio

Abrir el archivo `index.html` en un navegador web.

También puede utilizarse la extensión **Live Server** de Visual Studio Code para visualizar el sitio durante su desarrollo.

## Diseño e identidad visual

La propuesta visual está inspirada en la iluminación y el ambiente de los mercados nocturnos de Chinatown, utilizando una combinación de colores cálidos y oscuros.

| Color | Código | Aplicación |
|---|---|---|
| Marfil | `#F7F0E5` | Fondos generales |
| Rojo vino | `#8F1D2C` | Encabezados y elementos principales |
| Dorado | `#D39A18` | Acentos y elementos destacados |
| Azul oscuro | `#233B6E` | Botones e interacciones |
| Carbón | `#1B2428` | Contrastes y pie de página |

La interfaz combina banners, fotografías, tarjetas informativas y secciones de contenido para ofrecer una navegación organizada.

## Páginas del sitio

### Inicio
Presenta el Mercado Nocturno, sus experiencias culturales y gastronómicas, la agenda de actividades y la ubicación del evento.

### Historia
Expone el contexto histórico y cultural del Barrio Chino de Guayaquil.

### Emprende
Ofrece información sobre la participación de emprendedores y un espacio para presentar propuestas.

### Aliados
Da a conocer las organizaciones colaboradoras y ofrece información para posibles aliados interesados en apoyar el evento.

### Comunidad
Reúne experiencias de los visitantes y ofrece un espacio para compartir opiniones y sugerencias.
